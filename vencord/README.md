# ✦ Vencord (Discord)
⚠️ client mods break Discord's ToS — your call.
1. Download the installer from vencord.dev → Install (close Discord first).
2. Copy `lost-galaxy.theme.css` to `%APPDATA%\Vencord\themes\` (install-preview does this).
3. Discord → Settings → Vencord → Themes → enable **Lost Galaxy**.
