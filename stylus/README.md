# ✦ Stylus (Opera GX)
1. Install **Stylus** from the Chrome Web Store (Opera GX allows Chrome extensions).
2. Open `lost-galaxy-global.user.css` in Opera (drag the file into a tab) → **Install style**.
3. Dark themes for popular sites (GitHub, YouTube, Wikipedia, Google…): Catppuccin userstyles
   → Stylus → Manage → Import → the `import.json` from github.com/catppuccin/userstyles (releases) → set flavor **mocha**, accent **mauve**.

Opera GX itself: GX Control → Theme → custom: primary `#CBA6F7`, background `#11111B`.
